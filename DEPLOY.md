# Deployment Guide

Deploy **backend → Render**, **frontend → Vercel**, **database → Neon** (all free tier).

## Step 1 — Neon Database (5 min)

1. Go to [neon.tech](https://neon.tech) → Sign up → **New Project**
2. Copy the connection string (looks like `postgresql://user:pass@host/neondb?sslmode=require`)
3. Keep this for Step 2

## Step 2 — Deploy Backend (Render)

1. Push code to GitHub (see below)
2. Go to [render.com](https://render.com) → **New +** → **Blueprint**
3. Connect repo `Satvik0609/Fundsroom`
4. Render reads `render.yaml` automatically
5. Set environment variables when prompted:
   | Key | Value |
   |-----|-------|
   | `DATABASE_URL` | Your Neon connection string |
   | `CORS_ORIGIN` | `https://YOUR-VERCEL-APP.vercel.app` (update after Step 3) |
   | `JWT_SECRET` | Auto-generated by Render |
6. Deploy → copy your backend URL (e.g. `https://mini-erp-crm-api.onrender.com`)

## Step 3 — Seed Production Database (once)

In Render dashboard → your service → **Shell**:

```bash
npm run db:seed
```

Or run locally pointing at Neon:

```powershell
cd backend
$env:DATABASE_URL="your-neon-connection-string"
npm run db:seed
```

## Step 4 — Deploy Frontend (Vercel)

1. Go to [vercel.com](https://vercel.com) → **Add New Project**
2. Import repo `Satvik0609/Fundsroom`
3. Set **Root Directory** to `frontend`
4. Add environment variable:
   | Key | Value |
   |-----|-------|
   | `VITE_API_URL` | `https://mini-erp-crm-api.onrender.com` (your Render URL) |
5. Deploy → copy Vercel URL (e.g. `https://fundsroom.vercel.app`)

## Step 5 — Update CORS

Go back to Render → Environment → set:

```
CORS_ORIGIN=https://YOUR-VERCEL-URL.vercel.app
```

Redeploy backend.

## Step 6 — Verify

1. Open your Vercel URL
2. Login: `admin@erp.local` / `Pass@123`
3. Test customer creation
